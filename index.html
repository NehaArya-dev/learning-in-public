001 - How Web Applications Work

A web application has a frontend and a backend. The frontend sends a request to the server. The backend processes the request and sends a response back. When you enter a website address, your browser sends an HTTP request to a server. The server responds with resources such as HTML, CSS and JavaScript. The browser uses those resources to display the website. Once the application is running, the frontend may make additional requests to backend APIs to retrieve or change data. Frontend — what the user interacts with. Buttons, forms, tables, dashboards, menus. Backend — handles the application's logic.

The backend handles application logic and processes requests.

For example, it may determine:

  • Is this user logged in?
  • Can this user edit this customer?
  • Is this phone number valid?
  • Should this lead be saved?
  • What data should appear on the dashboard?

Database

The database stores and organizes application data so it can be retrieved and changed when needed.

Database — stores information permanently.
